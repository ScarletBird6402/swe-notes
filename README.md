## 카테고리

| 블록 | 카테고리 |
|---|---|
| 클라이언트 | A 프론트엔드 · B 웹 플랫폼/브라우저 |
| 서버 · 데이터 | C 백엔드 · D API/통신/메시징 · E 데이터베이스 · F 데이터 엔지니어링 · G 동시성/비동기 · H 분산 시스템 |
| 설계 · 품질 · 협업 | I 설계/아키텍처 · J 테스트/품질 · K 개발 방법론/협업 · L 버전 관리(Git) |
| 운영 · 플랫폼 | M 빌드/패키지/배포 · N 클라우드 · O 운영/인프라/디버깅 · P 관측성/모니터링 · Q 성능/최적화 · R 고가용성/장애허용 |
| 보안 | S 보안(애플리케이션) · T 데이터 보호/프라이버시 · U 네트워크/인프라 보안 |
| CS · 통신 | V 운영체제 · W 컴퓨터구조 · X 임베디드(예약) · Y 네트워크(유선) |
| 설계·통합 프로젝트 | Z 시스템 설계·통합 프로젝트 |

폴더 = 카테고리(`코드 카테고리명`), 파일명 = `코드 제목.html`(예: `I4 의존성 주입과 테스트 용이성.html`).
전체 목차와 게시 현황은 [문서 사이트](https://ScarletBird6402.github.io/swe-notes/)에서 볼 수 있습니다.

## 학습 계획

전체 계획표는 [CURRICULUM.md](CURRICULUM.md)에 있습니다.
**업무에서 다루는 주제 순으로 우선 학습**하며, 계획에 없던 항목은 신규 코드를 부여해 편입합니다.
코드 체계는 고정이라(재사용 없음) 문서 파일명·링크가 안정적으로 유지됩니다.
Z(시스템 설계·통합 프로젝트)는 설계 시나리오를 문서로 정리하고 실제 구현으로 잇는 카테고리입니다.
X(임베디드)는 예약 카테고리로, 다른 카테고리의 계획 항목이 대부분 소진된 뒤에 다룰 수도 있는 영역이며 개시 여부는 정해져 있지 않습니다.
